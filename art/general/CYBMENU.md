# CYBMENU.ANS

The framework's main menu: the menu's options in two columns on deep blue
and purple, the board's name above them (`%BN`), a rumour (`%RR1`, kept
to the 38 columns left of the figure) and the node number (`%ND`) below,
as the stock menu has them, beside a woman in a glowing VR headset on
bright magenta. 80x22, 16 colours; the main menu's prompt draws below it.
`./oputil.js config hub` makes it a hub board's main menu art
(`--stock-menu` keeps the stock one); any board can name it as its main
menu's `art`.
