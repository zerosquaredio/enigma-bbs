# CYBMENU.ANS

The framework's main menu: the menu's options in two columns, the board's
name above them (`%BN`), a rumour (`%RR1`) and the node number (`%ND`)
below, as the stock menu has them, beside a cyberpunk figure in a glowing
VR visor on a magenta panel. 80x22, 16 colours; the main menu's prompt
draws below it. `./oputil.js config hub` makes it a hub board's main menu
art (`--stock-menu` keeps the stock one); any board can name it as its
main menu's `art`.
